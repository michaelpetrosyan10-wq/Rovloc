ROVLOC voice auditions

These are test voices: tell us which you like. Every voice here is made by a computer speech model: the models' own built-in voices, mixed and changed by us. No real person's voice was cloned, and no one was recorded for this page. The lines are only tests, the real script comes later.

For each character there are 2 or 3 voices (A, B, C). Press play, listen, and tell us which one sounds right, for example "Danny A, Marcus B, Priya A, Gus C, monster M2". If none fits, say what is wrong ("too old", "too slow", "sounds like a robot").

Under each line: whether a speech recogniser understood every word, the length, the voice's pitch and how fast it talks (words per second). Use headphones or a quiet room.

Saying your name

The game cannot know your name in advance, so the monster says common first names from a bank (each its own small file) and the game plays the name, a short beat, then the rest of the line, overlapping the two files a little so there is no gap. If your name is not in the bank, it uses the line without a name. Here: the name and the rest joined the way the game will play them, then the line without the name.
